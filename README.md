# ⚡ FLUX Engine v1.0
**A Predictive Cognitive Resource Management Tool**

FLUX Engine is a specialized dashboard designed to track and predict academic burnout. 
By analyzing "Energy Drain" across different engineering domains and correlating it 
with focus efficiency, the system provides a real-time "System Health" telemetry.

### Key Features:
- **Heuristic Engine:** Weighted drain factors for high-complexity subjects.
- **Predictive Analytics:** Rolling-average burnout risk assessment.
- **Persistence:** Local CSV-based data logging for longitudinal tracking.
- **UI/UX:** High-contrast Dark Mode optimized for reduced eye strain.
